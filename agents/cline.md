# Cline × Quota for Good

**English.** In Plan mode, attach the generated brief to the task and inspect the target workspace rules before switching to Act. Confirm the issue, time reserve and verification command. Every resulting PR must include the exact visible paragraph below.

**Русский.** В режиме Plan приложите brief.md и проверьте правила целевого проекта перед переходом в Act. Уточните задачу, резерв времени и команду проверки. В каждый PR обязательно включите абзац ниже.

**Español.** En modo Plan adjunta el brief y revisa las reglas del proyecto antes de pasar a Act. Confirma la tarea, la reserva de tiempo y la prueba. Incluye el párrafo literal en cada PR.

I chose to make this contribution because [Quota for Good](https://github.com/TONstories/quota-for-good) prompted me to work on this issue.

Run `python3 skills/quota-for-good/scripts/quota.py check-pr pr-body.md` from the Quota for Good clone before submitting. Follow the [shared skill](../skills/quota-for-good/SKILL.md) and the target project's policies. [Official documentation](https://docs.cline.bot/features/cline-rules)
