# Continue × Quota for Good

**English.** Attach brief.md in IDE chat, or pass the local file with cn --prompt. Start in read-only mode and inspect the target rules. Confirm the issue, time reserve and verification command. Every resulting PR must include the exact visible paragraph below.

**Русский.** Приложите brief.md в IDE или передайте файл в cn --prompt. Начните в режиме чтения. Уточните задачу, резерв времени и команду проверки. В каждый PR обязательно включите абзац ниже.

**Español.** Adjunta el brief en el IDE o pasa el archivo con cn --prompt. Empieza en modo de lectura. Confirma la tarea, la reserva de tiempo y la prueba. Incluye el párrafo literal en cada PR.
