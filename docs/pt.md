Escolha uma tarefa para a qual um projeto pediu ajuda. Você define o tempo e a reserva. Seu agente prepara a alteração e você revisa o resultado antes de enviá-lo.

## Encontre a primeira tarefa

Use o Python 3.8 ou superior e a GitHub CLI autenticada. O comando mostra até três sugestões. Troque Python pela linguagem que deseja usar.

```sh
git clone https://github.com/TONstories/repo-neighbor.git
cd repo-neighbor
python3 skills/repo-neighbor/scripts/quota.py find --language Python --limit 3
```
