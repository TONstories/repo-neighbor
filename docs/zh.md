选择一个正在寻求帮助的开源项目，设定可用时间，并为自己的工作预留额度。让编程助手准备修改，由你检查后决定是否提交。

## 寻找第一个任务

需要 Python 3.8 或更高版本，并已通过 GitHub CLI 登录。以下命令最多列出三个候选任务。可以将 Python 替换为你熟悉的编程语言。

```sh
git clone https://github.com/TONstories/repo-neighbor.git
cd repo-neighbor
python3 skills/repo-neighbor/scripts/quota.py find --language Python --limit 3
```
