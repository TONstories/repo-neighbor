Choisissez une tâche pour laquelle un projet demande de l’aide. Vous fixez la durée et gardez une réserve. Votre agent prépare une modification que vous relisez avant son envoi.

## Trouver une première tâche

Il vous faut Python 3.8 ou plus et GitHub CLI connecté à votre compte. Cette commande propose jusqu’à trois tâches. Remplacez Python par le langage de votre choix.

```sh
git clone https://github.com/TONstories/repo-neighbor.git
cd repo-neighbor
python3 skills/repo-neighbor/scripts/quota.py find --language Python --limit 3
```
