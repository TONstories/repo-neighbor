## Знайдіть перше завдання

Потрібні Python 3.8 або новіший і GitHub CLI з виконаним входом. Команда покаже до трьох варіантів. Замініть Python на потрібну мову програмування.

```sh
git clone https://github.com/TONstories/repo-neighbor.git
cd repo-neighbor
python3 skills/repo-neighbor/scripts/quota.py find --language Python --limit 3
```
