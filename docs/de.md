Wähle eine Aufgabe, für die ein Projekt Hilfe sucht. Du legst Zeit und Reserve fest. Dein Agent bereitet eine Änderung vor, die du vor dem Versand prüfst.

## Erste Aufgabe finden

Du brauchst Python ab 3.8 und eine angemeldete GitHub CLI. Der Befehl zeigt bis zu drei Vorschläge. Ersetze Python durch deine bevorzugte Programmiersprache.

```sh
git clone https://github.com/TONstories/repo-neighbor.git
cd repo-neighbor
python3 skills/repo-neighbor/scripts/quota.py find --language Python --limit 3
```
